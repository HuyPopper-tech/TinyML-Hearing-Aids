# Nuvoton OpenOCD tooling

The main [M55M1 flash, Cortex-Debug and recovery guide](../../docs/M55M1_OPENOCD_DEBUG.md)
is maintained under `docs/`. It covers installation, VS Code profiles and tasks,
manual commands, SWD wiring, APROM boundaries and verified limitations.

This directory contains the project configuration, pinned distribution manifest
and installer. The official vendor runtime is installed locally in `.runtime/`
and remains ignored by Git.
