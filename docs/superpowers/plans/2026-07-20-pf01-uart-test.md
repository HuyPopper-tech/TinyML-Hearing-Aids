# PF0/PF1 UART0 Test Firmware Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an opt-in PF0/PF1 UART0 test image that repeats a 115200-baud banner on PF0.

**Architecture:** Keep the current DMIC app as default. A cache string selects either `app/main.c` or the separate `app/pf01_uart_test.c`; tests statically enforce the pin-mux and recovery-safety contract.

**Tech Stack:** CMake, Arm Compiler 6, Nuvoton StdDriver, Python unittest.

## Global Constraints

- `M55M1_FIRMWARE_MODE` defaults to `dmic`.
- `pf01_uart` uses PF0 as UART0 TXD and PF1 as UART0 RXD at 115200-8-N-1.
- Test UART output is J2.2/PF0 to a 3.3 V USB-to-TTL RX with common ground; disconnect WCH-Link while the test runs.
- This revision must not call ICE or DPM debug-protection APIs.

```python
def test_pf01_uart_test_uses_uart0_and_never_restores_ice(self):
    source = (REPO_ROOT / "app" / "pf01_uart_test.c").read_text(encoding="utf-8")
    for required in ("SET_UART0_TXD_PF0();", "SET_UART0_RXD_PF1();", "CLK_EnableModuleClock(UART0_MODULE);", "CLK_UARTSEL0_UART0SEL_HIRC", "UART_Open(UART0, 115200UL);", "UART_Write(UART0,"):
        self.assertIn(required, source)
    for forbidden in ("SET_ICE_DAT_PF0", "SET_ICE_CLK_PF1", "DPM_SetDebug"):
        self.assertNotIn(forbidden, source)
```
