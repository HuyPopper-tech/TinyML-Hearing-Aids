# DeepFilterNet U55 deployment contract

## Ownership and identity

Production firmware links only `deepfilternet_u55_full_seed20260805`.
`deepfilternet/` is the immutable user export; `models/deepfilternet/` is the
firmware package generated by `tools/generate_deepfilternet_assets.py`.

The selected post-Vela model is 1,197,856 bytes with SHA-256
`7ee81189598812499796635c3f88ae4c4bca1ff9be81c79ceb4d1fd6d723e475`.
Its audited contract has one `ethos-u` custom operator, 9 inputs, 10 outputs,
21 tensors, 1,174,528 MAC/frame, 426 NPU operators and 0 CPU operators.

## Runtime boundary

`deepfilternet_inference` owns the TFLM interpreter, 256 KiB bring-up arena,
all recurrent/cache tensors and transactional state commit. Reset uses each
input tensor's quantized zero-point. `next_df_state_0` is requantized; equal
quantization states are copied. Invoke failure publishes neither outputs nor
state and resets neural state.

`deepfilternet_audio_enhancer` owns 512/256 STFT/WOLA and five-frame complex
DF history. Frontend math is magnitude (not power), ERB analysis then
`log(max(x, 1e-6))`, plus real/imag bins 0..143. Gain covers 257 bins; complex
DF covers bins 0..143; upper bins retain the gain-masked spectrum.

DSP modes:

- `SCALAR`: KissFFT oracle for host/golden work.
- `MVE`: CMSIS-DSP MVEF RFFT/IFFT, vector multiply/dot/complex-MAC/add/scale.
- `PARITY`: same spectrum and model tensors feed scalar and MVE postprocess;
  firmware records maximum PCM delta and violations above 1 LSB.

Production Release accepts only `MVE`. A fixed-point FFT branch is not enabled
without measured MVEF timing above 16 ms.

## Telemetry and recovery

Diagnostics use foreground UART1 PA2/PA3 at 115200-8N1. A snapshot every 100
frames is deferred when capture is pending and enqueued atomically. It reports
stage/transport timing, model/arena/DSP/stack data, all quantized ranges and
saturation, PCM levels, parity and cumulative failure counters.

Before flashing, preserve access to PF0 SWDIO, PF1 SWCLK, nRESET, GND and
VREF/3V3. Do not record board acceptance without captured hardware evidence.
